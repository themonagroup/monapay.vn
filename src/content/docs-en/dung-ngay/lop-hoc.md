A parent transfers tuition without confirming, and staff spend end of month combing through a bank statement trying to match names, tripped up by duplicate names or a payment a few thousand short. This page shows small classes and training centres how to use MONA Pay so tuition confirms itself the moment a parent pays.

## What it looks like once it is set up

At the start of the month, staff send a payment link in the parents' Zalo group, pre-filled with the exact tuition amount for each child. A parent taps the link and confirms in their banking app, no need to remember the centre's account number.

The moment the money lands, the staff Zalo group gets an alert with the student's name and amount, and the parent receives a confirmation email to use as a receipt. No more opening a bank statement to match names by hand.

## Set it up in 3 steps

### 1. Connect the bank account

At [my.monapay.vn](https://my.monapay.vn), create an account, then under Bank enter the account number and phone number registered with the bank, confirmed with two OTP codes.

### 2. Add a Zalo group for staff

Add the staff handling tuition and accounting if any, then add the MONA Pay bot. Every payment now becomes a message in the group.

### 3. Send a payment link or QR code per student

Under Hosted checkout in the dashboard, create a link for the exact tuition amount, name it after the student, and send it in the parents' group each month, or print a QR code for parents paying in person.

## Tips for classes and training centres

**Ask parents to include the student's name in the note**, or use a separate link per student, so two same-amount payments in one session never get mixed up.

**Use the confirmation email as a receipt** when a parent asks "did I already pay", instead of digging through a paper log.

**Split by virtual account for multiple classes**, so the owner can filter the dashboard by class or location at month end instead of adding up statement lines by hand.
